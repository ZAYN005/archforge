# Space Fractions

The Space Fractions system is a web-based, interactive learning tool designed to improve fraction-solving skills for sixth-grade students. The system consists of an introductory movie, a main menu, a series of fraction questions, and an ending scene with feedback. The architecture will follow a microservices approach, with separate components for the game logic, question management, and user interface. The system will be deployed on a cloud-based infrastructure, ensuring scalability and availability.

## Run it

```bash
npm install          # first time (downloads Electron)
npm start            # desktop app (Electron window)
npm test             # Jest test suite
npm run server       # headless REST API on http://localhost:3000
npm run dist         # build a portable Windows .exe into dist/

```

**Admin screen / admin API:** the admin token protects the question bank (ASR-2). Default: `dev-admin-token`; set your own before starting: `set ADMIN_TOKEN=your-secret` (Windows) or `export ADMIN_TOKEN=your-secret`. API clients send it in the `x-admin-token` header.

## Architecture

The system is an Express 4 desktop game served to an Electron shell. The core domain owns fraction value comparison, the legal game state machine, and seed questions, while a swappable store (memory or atomic JSON file) preserves data. Game routes call GameService to start games, serve shuffled options without revealing the correct answer, score answers by value, and expose pause/resume/quit transitions. Admin routes require x-admin-token and use QuestionService to list or replace the question bank. Electron serves the public UI flow: intro movie, main menu, questions, and ending feedback.

Modular monolith: one module per architecture component, each with its own router/service, talking through interfaces, inside one process (see lint finding on microservices vs. single deployment).

| Component | Folder | Responsibility |
|---|---|---|
| GameComponent | `src/components/game/` | responsible for game logic and user interaction |
| QuestionComponent | `src/components/question/` | responsible for question management and data persistence |
| UserComponent | `src/components/user/` | responsible for user authentication and authorization |
| AdminComponent | `src/components/admin/` | handles update questions for the Admin actor |

## Game state machine

`Playing` --pause()--> `Paused`; `Paused` --resume()--> `Playing`; `Playing` --gameOver()--> `GameOver`; `Paused` --quit()--> `GameOver`. Illegal transitions return HTTP 409.
